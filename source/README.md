# Portfolio source

React source for the site served from this branch's root (GitHub Pages at `/Portfolio/`).
Recovered from the production source maps, then the admin dashboard was redesigned.

```bash
npm install
npm start               # dev server
npm run publish:pages   # build and copy the output to the repo root
```

Admin: `#/login`, then `#/admin/overview`. Design rules: `.claude/skills/design-taste-frontend`.
